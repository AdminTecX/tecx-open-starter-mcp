# TecX AI — Open Starter MCP Server (Free)

A lightweight Model Context Protocol (MCP) server for Claude Desktop, Cursor, and Gemini CLI that validates GSTIN formats and previews customer order notifications locally.

## Quick Install
```bash
git clone https://github.com
cd tecx-open-starter-mcp
npm install
```
